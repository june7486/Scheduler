2️⃣ 저장된 데이터 찾기

브라우저에 저장된 June's Scheduler 데이터베이스를 모두 검색합니다. 찾은 데이터는 화면에만 표시되며 어디로도 전송되지 않습니다.

3️⃣ 복원 방법

  1. 위 ⬇ 백업 파일 내려받기를 눌러 june_scheduler_backup_….json 파일을 저장합니다.
  2. www.aqdesign.co.kr 로 이동해 로그인합니다.
  3. 설정 → 데이터 → 파일에서 복원 을 눌러 방금 받은 파일을 선택합니다.
  4. 일정·탭·음성메모가 그대로 되살아납니다. 🎉

데이터를 찾지 못했다면, 예전 데이터를 입력했던 그 브라우저에서 이 페이지를 열었는지 확인해 주세요. (시크릿 모드·다른 기기·브라우저 데이터 삭제 시에는 복구할 수 없습니다.)
