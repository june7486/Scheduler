# 계정 초기화 런북 — 2026-11-21

> **한 줄 결론**: 복구가 안 되면 `reset_accounts.py` 로 **마스터 1개만 새로 심고 나머지는 잠급니다**.
> 일정은 그대로 남습니다. 되돌리려면 백업 폴더에서 복사하면 됩니다.

## 0. 먼저 — "복구"와 "초기화"의 차이

| | 복구 | 초기화 |
|---|---|---|
| 뜻 | 옛 비밀번호를 되살림 | 마스터 1개만 새 비번으로, 나머지는 잠금 |
| 가능? | **불가능** (해시는 단방향) | 가능 |
| 일정 | 그대로 | 그대로 (기본값) |
| 계정 | 그대로 | 마스터 외 전부 잠김 |

비밀번호는 서버에 `pwHash`(SHA-256 256회 반복)로만 있습니다. **되돌릴 수 없습니다.**
그래서 "복구"는 실제로는 항상 "재설정"입니다.

## 2. 초기화 — 미리보기 먼저

```bash
sudo python3 reset_accounts.py data \
     --master-pw '새마스터비번' --master-name '이승준'
```

`--apply` 가 없으면 **파일을 한 바이트도 쓰지 않습니다.**
출력에서 확인할 것:

- `명부의 계정 행 : N개` — 잠글 계정 수
- `일정(tasks/) : M개 → 보존 (기본값)` — **M 이 0 이 아니면 일정이 있다는 뜻**
- 각 계정이 `→ 잠금` 인지 `(MASTER — 새 비번으로 다시 활성화)` 인지

## 3. 초기화 — 실제 실행

```bash
sudo python3 reset_accounts.py data \
     --master-pw '새마스터비번' --master-name '이승준' \
     --apply --yes-i-mean-it
```

안전장치 6중:

1. `--apply` 없으면 미리보기
2. `--apply` 만으로는 거부 — `--yes-i-mean-it` 필수
3. 실행 전 자동 백업 + **백업본 읽기 검증** (깨진 백업이면 중단)
4. 비번 4자 미만 거부 (앱 규칙)
5. 마스터는 반드시 남김
6. 기본 모드에서 `gen` 을 올리지 않음 → **안 보낸 로컬 작업이 날아가지 않음**

## 4. 왜 "삭제"가 아니라 "잠금(묘비)"인가  ★ 중요

행을 통째로 지우면 **옛 기기가 계정을 되살립니다.**

```
앱 publishAccountToRegistry()
  → 'enabled': u.enabled   ← 기기 로컬 값을 그대로 씀
  → 옛 기기가 로컬 사본으로 로그인 성공 → 그 행을 enabled:true 로 재발행
```

앱 코드 주석이 직접 말합니다:

> *"The row is kept, not removed: a tombstone is what lets every device see the decision"*

그래서 `reset_accounts.py` 는 두 가지를 함께 합니다.

1. `enabled: false` → 어떤 기기에서도 명부 검증 통과 불가
2. `pwHash` 를 **독극 해시(전부 0)** 로 치환 → 되살아난 행도 `inherited` 로 이 값을 물려받아 열리지 않음

**측정 결과** (새 행을 `enabled:true` 로 재발행시켜도):

```
되살아난 행으로 옛 비번 로그인 : 거부
되살아난 행으로 빈 비번 로그인 : 거부
```

## 5. 남은 위험 — 서버로 막을 수 없는 부분

**이미 그 계정으로 로그인한 적이 있는 기기**는 계속 들어옵니다.

```
authenticate()
  1) authenticateAgainstRegistry() → 명부가 enabled:false 로 거부 → null
  2) 폴백: local.password == pw ?  ← ★ 기기 로컬 사본(평문)에서 통과
  3) 로그인 성공 + 워크스페이스 코드는 결정적이므로 서버 일정도 그대로 열람
```

앱이 오프라인 로그인을 위해 `users` 박스에 **평문 비번**을 저장하기 때문입니다
(`models.dart:4 — String password; // plaintext for local-only app`).

**대응** (사용자 작업):
- 해당 기기에서 **앱 데이터 삭제** 또는 **앱 제거**
- `test` 계정은 매 부팅마다 다시 심어지므로 **릴리스 빌드에서 코드 제거** 필요
  (`store.dart:180-195 init()` → `_ensureTestUser()`)


## 8. 401 이 나올 때 (별개 문제)

`show_accounts.py` 의 `[4]` 가 `(다) 401` + `(가) 값 있음` 이면:

```bash
sudo cp .env .env.bak.$(date +%Y%m%d-%H%M%S)
sudo sed -i 's/^SYNC_SECRET=.*/SYNC_SECRET=/' .env
sudo systemctl restart june-gateway
```

`HOST=127.0.0.1` 이므로 루프백 밖에서는 접근할 수 없어 안전합니다.
`(라)` 가 `401` 이면 `.env` 의 키가 서비스가 쓰는 값과 다릅니다:
`sudo systemctl cat june-gateway | grep -i environment`
